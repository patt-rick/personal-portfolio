Store Room

2022

Visit ↗

Store Room is one of my earlier projects: an inventory and store-management interface, with pages for the dashboard, inventory, restocking and history.

It's built with Nuxt 2 and Vue 2, styled with SCSS, and uses the Nuxt PWA module so it can be installed like an app.

It's honest to call it a prototype. The screens and components are there (login and sign-up, dashboard cards, a line chart, tables, modals and an add-item form) but a backend was never wired in, so the data you see is sample data. It's here as an early piece of front-end work.

Built with

  • Nuxt 2
  • Vue 2
  • SCSS
  • Nuxt PWA
  • Axios
