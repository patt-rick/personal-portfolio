Sweep

November 2026 – now · v1.1.0

Download ↗

Sweep is a disk cleaner for programmers. Building lots of projects fills a drive fast, but not with photos or videos: with node_modules, target and dist folders, package caches, Docker images and old Android SDKs. Every cleaner I tried went after the wrong things. Sweep goes after exactly these, and frees gigabytes in one click.

What makes it different is that it only offers what can be rebuilt. A folder is only listed when its project file sits beside it (a package.json, a Cargo.toml), when git tracks nothing inside it, and when it isn't a link or a system folder. Projects with uncommitted changes are never ticked for you, and every check runs again the moment before anything is deleted. Caches are cleaned with each tool's own command (npm, pnpm, Yarn, pip, dotnet), and Docker with docker itself, so no tool is ever left with a half-deleted cache.

It lives quietly in the tray, rescans once a day and tells you when there's a lot to reclaim. Search, filter and sort to find a specific project, send things to the Recycle Bin instead of deleting them, or do a dry run first. A History page shows everything it has freed, an Explore view maps any drive by size, and it updates itself. It's free and open source.

Built with Rust, Tauri 2 and React.
