Class Tablr

March 2026

Visit ↗

Class Tablr builds school timetables. You set up classes, subjects and teachers, pick a day profile (start and end times, period length, breaks), then drag lessons onto a grid. Each school's data is kept separate, and a finished timetable exports to PDF.

It's a Next.js 16 app on the App Router, with a credentials login and Drizzle ORM on Postgres. It started on SQLite and moved to Postgres early on; the first version came together over two days in March 2026.

Catching clashes

When you drop a lesson, it checks every other class on the same day: for each period the lesson would cover, is that teacher already teaching somewhere else? Lessons can span several periods, so for a merged block it walks back to the start of the block to find who's assigned. A toast flags the clash straight away.

Building the day

The grid is generated from the profile: periods interleaved with breaks. If the day ends with less than ten minutes left over, that sliver is dropped instead of becoming a useless period; otherwise the last period is shortened to fit. Saved lessons are then laid back over the regenerated grid.

Built with

  • React 19
  • TypeScript
  • Auth.js
  • Drizzle ORM
  • Postgres
  • Tailwind
  • react-pdf
